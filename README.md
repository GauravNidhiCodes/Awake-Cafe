
# AWAKE Cafe

A responsive multi-page cafe website built using HTML, CSS and JavaScript.

## About the Project

AWAKE Cafe is a coffee-inspired website with a clean, minimal design. Visitors can explore the menu, view cafe images and submit a sample table booking request.

## Features

- Home page with hero section and featured items
- Menu page with structured HTML tables
- Gallery with six images and video controls
- Click-to-enlarge gallery lightbox
- Booking form with built-in HTML validation
- Responsive layout for mobile, tablet and desktop
- Dark and light mode with saved preference
- Mobile hamburger navigation
- Embedded Google Maps location

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images
- Google Maps Embed

## How to Run

1. Download or clone the project repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or run it using the Live Server extension.
4. Use the navigation links to visit the other pages.

## Booking Form Notice

The booking form currently performs client-side validation and displays a demo success message. It does not send real reservations to a server.
